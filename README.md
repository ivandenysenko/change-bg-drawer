## 1. Task Objective

This is implementation of a "Change background" sidebar component using React, Typescript, Shadcn and Tailwind, prioritizing a pixel-perfect match with Figma design.

## 2. Trade-offs and Decisions

State managers were intentionally avoided to focus purely on creating high-quality markup and composition using local state.

Due to the absence of a formal design system, spacing values were visually inferred rather than tokenized, which may require future standardization.

While Shadcn UI accelerated development, it introduced some unused utility code that will need to be pruned in a future cleanup phase.
